# Latent Vibe

The source for the Latent Vibe homepage. The static site is in `dist/index.html`.

Products use their own subdomains. The homepage links to public products; each product can be deployed independently. Existing Cloudflare DNS records for product subdomains are managed outside this repository.

To update the homepage, edit `dist/index.html` and publish the site. Add ideas and publications only when their content is ready.
